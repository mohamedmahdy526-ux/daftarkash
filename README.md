# دفتر كاش (DaftarKash) 📒🛒

تطبيق ويب تقدمي (PWA) ذكي وشامل لإدارة حسابات المحلات التجارية والبقالة والسوبرماركت، مدعوم بمحرك قارئ باركود فائق السرعة ومزامنة سحابية مع Google Sheets.

## ✨ المميزات الرئيسية:
- 📒 **دفتر حسابات ديون وسداد للعملاء:** تسجيل الديون والدفعات، حساب فوري للأرصدة، وفرز الحسابات.
- 🛒 **محرك قارئ باركود فائق السرعة (HD Scanner):** قراءة سريعة لباركود المنتجات بالكاميرا أو بمسدس الباركود.
- ☁️ **مزامنة سحابية حية مع Google Sheets:** حفظ فوري وتلقائي للعملاء، المعاملات، والمنتجات.
- 📊 **تصدير واستيراد إكسيل (Excel):** تصدير كشوفات الحسابات وقوائم المنتجات بالكامل.
- 💬 **إرسال كشوف الحسابات عبر واتساب:** بنقرة واحدة بدون حفظ الرقم.
- 📄 **طباعة فواتير وكشوف حساب PDF احترافية.**
- 🌓 **وضع ليلي ونهاري متجاوب مع الهواتف الذكية.**
- 🔤 **تحكم كامل في حجم الخط والقراءة للكاشير.**
- 📡 **يعمل بدون إنترنت (Offline-First) مع مزامنة تلقائية عند الاتصال.**

## 🚀 التشغيل محلياً:
فقط افتح `index.html` في أي متصفح، أو قم بتشغيل خادم محلي:
```bash
python -m http.server 5500
```
