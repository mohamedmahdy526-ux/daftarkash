# دفتر كاش (DaftarKash) 📒🛒

تطبيق أندرويد متكامل وحديث مبني بتقنيات **Android Jetpack Compose & Room Database** لإدارة حسابات المحلات التجارية، البقالة، والسوبرماركت، مع دعم الإدخال الصوتي الذكي والمزامنة السحابية الحية مع Google Sheets.

## ✨ المميزات الرئيسية:
- 📒 **دفتر حسابات ديون وسداد العملاء:** تسجيل الديون والدفعات، حساب فوري للأرصدة، وفرز الحسابات (عليهم فلوس / خالصين / الأعلى ديناً).
- 🎙️ **إدخال صوتي ذكي بالذكاء الاصطناعي:** التعرف على الصوت المصري والعربي، والفرز الذكي بين كميات البضائع ومبالغ الفواتير مع الجمع التراكمي.
- 🧮 **آلة حاسبة سريعة ومدمجة:** إجراء الحسابات فوراً وتحويل الناتج مباشرة إلى دين على حساب العميل بنقرة واحدة.
- ☁️ **مزامنة سحابية ثنائية مع Google Sheets:** حفظ وتحديث فوري وتلقائي للعملاء، المعاملات، وقوائم الأسعار في الشيت.
- 📄 **توليد كشوف حسابات وفواتير PDF:** تصميم احترافي يدعم اللغة العربية بالكامل (RTL) مع الختم الرسمي للمحل (Rubber Stamp) ودعم تعدد الصفحات.
- 📊 **تصدير شيت إكسيل (Excel / CSV):** تصدير كامل البيانات بترميز UTF-8 BOM لفتحها فوراً في Microsoft Excel بدون أي مشاكل في اللغة العربية.
- 💬 **مشاركة كشوف الحسابات عبر واتساب:** إرسال كشف حساب منسق بنقرة واحدة بدون الحاجة لحفظ الرقم مسبقاً.
- 📱 **استيراد جهات الاتصال:** اختيار اسم ورقم العميل مباشرة من سجل هاتف المحل.
- 🌓 **وضع ليلي ونهاري متجاوب مع مؤثرات صوتية:** أصوات تفاعلية للكاشير ونغمات احتفالية عند اكتمال السداد.
- 📡 **يعمل أوفلاين بالكامل (Offline-First):** سرعة فائقة مع قاعدة بيانات Room محلية ومزامنة تلقائية عند توفر الإنترنت.

## 🛠️ التقنيات المستخدمة:
- **Kotlin & Jetpack Compose (Material 3)**
- **Room Database & SQLite**
- **Kotlin Coroutines & StateFlow / SharedFlow**
- **Android PdfDocument & FileProvider**
- **OkHttp3 & Kotlinx Serialization**
